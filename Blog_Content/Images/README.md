# Image Directory Structure

This directory contains optimized images for blog posts in both JPG and WebP formats.

## Naming Convention
- Use descriptive, kebab-case names
- Include date prefix for better organization
- Example: `2024-03-26-market-manipulation-header.jpg`

## Image Specifications
- Maximum width: 1200px
- Formats: JPG and WebP
- Optimized for web delivery
- Maintained aspect ratios
- Compressed without quality loss

## Organization
Images are stored in subdirectories by month:
```
Images/
├── 2024-03/
├── 2024-04/
└── README.md
```
